# Awesome-Corporate-Learning-Experience

### Top Corporate Learning Experience (LXP) Platforms Ecosystem

**Curated List of SaaS/Hosted Platforms & Open-Source GitHub Projects**  
*Focused on Corporate Learning Experience, Personalized Learning, Skills Development, Content Curation & Workforce Upskilling*  
**Last updated: August 2026**

This repository tracks notable **SaaS/Hosted Platforms** and **open-source projects** for **Corporate Learning Experience Platforms (LXP)**. These tools help organizations aggregate learning content, personalize employee learning, curate internal and external resources, develop skills, create learning pathways, enable social learning, recommend content, and measure workforce development.

**Examples** include Degreed, EdCast, 360Learning, Docebo, Learn Amp, Valamis, Cornerstone Learning Experience, HowNow, Disprz, and Thrive Learning.

Modern LXPs increasingly combine **AI-powered recommendations, skills graphs, content aggregation, learning pathways, social learning, knowledge sharing, course authoring, learning analytics, career development, skills-gap analysis, internal mobility, and learning-in-the-flow-of-work**. Degreed, for example, describes its LXP around personalized feeds, skills profiles, content aggregation, pathways, recommendations, and integrations with LMS/HCM systems. :contentReference[oaicite:0]{index=0}

**Open-source emphasis**: This repository is heavily expanded with open-source projects that can be used to build custom learning-experience ecosystems — including LMS/LXP foundations, learning-content platforms, learning-record stores, xAPI infrastructure, recommendation engines, knowledge bases, course-authoring systems, social-learning platforms, skills graphs, analytics, and AI-powered learning assistants.

The open-source ecosystem is particularly useful because an LXP is fundamentally a **composable system**: content + learner profile + skills + recommendations + learning records + social/knowledge layer + analytics + integrations.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites or GitHub repositories.

## Open-Source GitHub Projects

> **Important:** There is no single open-source project that completely reproduces Degreed, EdCast, 360Learning, Docebo, or Cornerstone Learning Experience. The strongest open-source approach is to combine **LMS/LXP infrastructure + content management + learning records + xAPI + recommendations + skills + analytics + social learning + AI**.

- **[OpenLXP](https://github.com/educateschools/openlxp)**

- **[Open edX](https://github.com/openedx/edx-platform)**  
  Large-scale open-source learning platform providing course authoring, course delivery, certificates, learner management, and analytics. Its modular architecture makes it a strong foundation for customized enterprise learning environments. :contentReference[oaicite:4]{index=4}
